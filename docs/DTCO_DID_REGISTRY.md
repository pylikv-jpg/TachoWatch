# TachoWatch — DTCO DID registry

Единый рабочий реестр найденных и расшифрованных каналов DTCO. Этот файл является источником истины для дальнейшей разработки сканеров и TachoWatch. Ошибочные гипотезы не удаляются бесследно: они помечаются как отменённые, чтобы не повторять их позже.

## Подтверждённые / практически подтверждённые DID

| DID | Статус | Назначение | Наблюдения / примечание |
|---|---|---|---|
| F905 | рабочая расшифровка | Признак движения автомобиля | Используется как динамический признак движения. |
| F906 | рабочая расшифровка | Состояния/предупреждения водителя, включая флаги лимитов | Требует дальнейшей побитовой детализации, но канал полезный и динамический. |
| F916 | подтверждён | Данные карты водителя (LV/номер) | В наблюдениях содержит идентификационные данные карты; ASCII позволял видеть имя/данные водителя. |
| F923 | подтверждён | Непрерывное вождение водителя 1 | 2026-09-08: первый период 251 мин = 4:11, второй 243 мин = 4:03. После полноценной 45-мин паузы начинается новый период. |
| F925 | подтверждён | Накопленное зачётное время пауз/отдыха для сброса непрерывного вождения | Не равно длительности текущей паузы. 2026-09-08 видно накопление предыдущих 15 мин + текущей части до 45 мин. |
| F927 | подтверждён | Длительность текущей выбранной деятельности | Растёт в рамках текущего режима и сбрасывается при смене деятельности. |
| F930 | подтверждён по ISO 16844-7 | TachographCardSlot1 | 0x01 = водительская карта присутствует в слоте 1. Больше не считать неизвестным кандидатом. |
| F938 | подтверждён | Суммарное вождение за предыдущую + текущую неделю | 2026-09-08: 2958→3452 мин, дельта 494 мин = 8:14; точно совпало с 4:11 + 4:03 по F923. Полезен как контроль и источник дельт вождения. |
| F979 | подтверждён по ISO 16844-7 | Synchronization Jump Width CAN | Технический параметр синхронизации CAN. Наблюдаемое 0x01. Для водительских счётчиков не нужен. |
| F9D5 | подтверждён по ISO 16844-7 | ByDefaultLoadType | 0x00 undefined, 0x01 Goods, 0x02 Passengers. В наблюдениях 0x01 = грузовой автомобиль. |
| F90B | подтверждён по ISO/J1939 | Time/Date тахографа | 8-байтовая дата/время. Прежняя гипотеза про счётчик сокращённых межсуточных отдыхов ОТМЕНЕНА. Изменение 0x02→0x03 соответствовало смене часа 02→03. |

## Целевые DID следующего исследования

Эти DID определены ISO 16844-7 и должны быть проверены на конкретном DTCO во время полной смены:

| DID | Назначение |
|---|---|
| F997 | Driver1EndOfLastDailyRestPeriod — окончание последнего суточного отдыха водителя 1 |
| F998 | Driver1EndOfLastWeeklyRestPeriod — окончание последнего недельного отдыха водителя 1 |
| F999 | Driver1EndOfSecondLastWeeklyRestPeriod — окончание предпоследнего недельного отдыха водителя 1 |
| F99A | Driver1CurrentDailyDrivingTime — текущее суточное вождение водителя 1 |
| F99B | Driver1CurrentWeeklyDrivingTime — текущее недельное вождение водителя 1 |
| F99C | Driver1TimeLeftUntilNewDailyRestPeriod — время до нового обязательного суточного отдыха |
| F99D | Driver1CardExpiryDate — срок действия карты |
| F99E | Driver1CardNextMandatoryDownloadDate — следующая обязательная выгрузка карты |
| F99F | TachographNextMandatoryDownloadDate — следующая обязательная выгрузка тахографа |
| F9A0 | Driver1NumberOfTimes9hDailyDrivingTimesExceeded — число использований >9 ч суточного вождения |
| F9A1 | Driver1TimeLeftUntilNewWeeklyRestPeriod — время до нового недельного отдыха |
| F9A2 | Driver1CumulativeUninterruptedRestTime — накопленный непрерывный отдых |
| F9A3 | Driver1MinimumDailyRest — минимальный требуемый суточный отдых |
| F9A4 | Driver1MinimumWeeklyRest — минимальный требуемый недельный отдых |
| F9A5 | Driver1MaximumDailyPeriod — максимальный суточный период |

## Правила использования в TachoWatch

- F923 остаётся основным прямым каналом для блока «Непрерывное вождение».
- F925 использовать как прогресс зачётной паузы, а не как длительность текущей паузы.
- F927 использовать для длительности текущей выбранной деятельности.
- F938 использовать как независимый контроль суммарного вождения и как возможный источник положительных дельт внутри смены. Не рассчитывать смену простой формулой `F938_now - F938_start` без обработки недельной границы.
- Если F99A реально поддерживается данным DTCO и стабильно совпадает с экраном тахографа, он станет предпочтительным прямым источником «Вождение за смену / суточное вождение» вместо реконструкции.
- F90B, F930, F979 и F9D5 больше не включать в список неизвестных динамических кандидатов.

## Важная исправленная гипотеза

F90B НЕ является счётчиком сокращённых межсуточных отдыхов. Это дата/время тахографа. Старое наблюдение изменения третьего байта 0x02→0x03 было переходом времени с 02:xx на 03:xx.
